# Pre-ICFES Saber 11

Página de estudio adaptable a celular, servida por Python estándar. No requiere instalar paquetes.

## Iniciar

1. Instala Python 3 si el equipo aún no lo tiene.
2. Abre una terminal en esta carpeta.
3. Ejecuta: **py app.py** (en macOS o Linux: **python3 app.py**).
4. En el computador abre **http://127.0.0.1:8765**.
5. Para estudiar desde el celular, conecta ambos dispositivos al mismo Wi-Fi y abre la dirección de red que aparece en la terminal.

Deja abierta la terminal durante el estudio. El progreso se guarda localmente en **progress.json**. Desde la sección “Tu camino” puedes borrar el historial cuando quieras. Si Windows muestra un aviso de firewall, permite el acceso solo en redes privadas.

Incluye práctica original para las cinco áreas, modos por área, práctica diaria, simulacro corto y práctica inteligente que prioriza el área de menor promedio. También ofrece repaso de errores, atajos con las teclas 1–4, explicaciones, diagnóstico por área, guía de competencias, estructura oficial, plan de siete días y enlaces de preparación del Icfes. Las preguntas son de elaboración propia, no son preguntas oficiales ni predicen el puntaje oficial.

La estructura descrita se basa en la Guía de Orientación Saber 11° 2026-2, Calendario A. Consulta siempre la guía vigente en el sitio del Icfes.
